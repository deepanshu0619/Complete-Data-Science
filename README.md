# Complete Data Science

This repository contains a set of data science learning projects covering data visualization, NumPy, Pandas, and machine learning workflows.

## Contents

- `Data-Visualization/`: Jupyter notebooks demonstrating categorical plots, distribution plots, Matplotlib, Plotly and Cufflinks, regression plots, and IPL capstone analysis.
- `Machine-Learning-Part-1/`: Introductory machine learning notebooks, including heart disease analysis and insurance datasets.
- `Machine-Learning-Part-3/`: A simple app and heart disease model notebooks.
- `Machine_learning_part4/`: Advanced machine learning topics such as clustering, ensemble learning, grid search, and PCA.
- `NumPy/`: Hands-on NumPy notebooks for arrays, indexing, and array operations.
- `Pandas/`: Pandas tutorials covering Series, DataFrames, missing data, merging/joining, aggregation, pivot tables, and feature extraction.

## Usage

Open the notebooks in Jupyter Notebook, JupyterLab, or VS Code with the Python extension. The project includes sample datasets used by the notebooks.

## Notes

- Keep the notebook environment consistent by using Anaconda or a Python virtual environment.
- Data files are included alongside the notebooks for easy exploration.
