# Complete Data Science

This repository is a collection of hands-on data science, machine learning, deep learning, and generative AI projects covering Python, NumPy, Pandas, visualization, ML workflows, NLP, and AI application development.

## Contents

- `CNN/`: Convolutional Neural Network notebooks and related exercises.
- `Data-Visualization/`: Jupyter notebooks for categorical plots, distribution plots, Matplotlib, Plotly, regression plots, and IPL capstone analysis.
- `Deep_learning/`: Introductory deep learning notebooks and examples.
- `GenAI/`: Generative AI experiments, chat models, Hugging Face integrations, and basic chatbot implementations.
- `GenAI Rag-implementation/`: RAG workflow implementation with vector stores, embeddings, document loaders, and retrievers.
- `Generative-AI/`: Agent-based, runnable chain, tool-calling, and prompt orchestration examples.
- `Machine-Learning-Part-1/`: Beginner-friendly machine learning notebooks, including heart disease and insurance datasets.
- `Machine-Learning-Part-3/`: A simple app and heart disease model notebooks.
- `Machine_learning_part4/`: Advanced machine learning topics such as clustering, ensemble learning, grid search, and PCA.
- `NLP/`: Natural language processing notebooks, including word embeddings and Game of Thrones Word2Vec experiments.
- `NumPy/`: Hands-on NumPy notebooks for arrays, indexing, and array operations.
- `numpy yt/`: Additional NumPy practice work with plots, arrays, and image-based examples.
- `Pandas/`: Pandas tutorials covering Series, DataFrames, missing data, merging/joining, aggregation, pivot tables, and feature extraction.
- `RNN-implementation/`: Recurrent Neural Network implementation examples and prediction workflows.

## Recent Additions

- `NLP/campusx-game-of-thrones-word2vec/`: Word2Vec NLP project focused on embeddings and text representation.
- `numpy yt/`: Extra NumPy practice files and small visual examples for learning and experimentation.

## Usage

Open the notebooks in Jupyter Notebook, JupyterLab, or VS Code with the Python extension. Most folders include sample datasets used by the notebooks.

## Notes

- Keep the notebook environment consistent by using Anaconda or a Python virtual environment.
- Many folders include their own requirements files or sample datasets for easy setup and practice.
- Data files and model artifacts are stored alongside the notebooks for direct exploration and hands-on learning.
